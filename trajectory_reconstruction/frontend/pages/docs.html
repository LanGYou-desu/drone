{{ icon_book() }} 帮助文档

鹰眼长空 — 基于多平台协同的低空无人机智能监测系统

快速入门

系统集成可见光、红外、雷达三种检测平台，支持上传自选数据。所有平台可加权合成为一条综合轨迹，用于整体分析和捕捉决策。

启动

  • 桌面窗口：python main.py
  • 仅重建分析：python main.py recon
  • 纯 HTTP：python main.py --headless（重建模块 :5000，识别模块 :5001）

配置

编辑项目根目录 config.json：

  • ai — 填入 API Key / URL / Model 后可使用 AI 策略
  • detection_methods[].weight — 综合轨迹合成权重
  • capture_weights — 最佳捕捉时机评分权重（高度/速度/加速度/曲率）
  • camera_speed — WASD 移动速度（默认 0.12）

功能模块

{{ icon_target() }} 总览

全屏 3D 视图展示所有平台轨迹。左侧面板切换平台可见性，同步影响后续页面。右侧面板实时显示速度/高度/航向角。底部控制栏播放轨迹动画，支持调速和拖拽进度。鼠标悬停球体显示三维坐标和时间戳。

{{ icon_predict() }} 轨迹预测

基于历史轨迹线性外推预测未来飞行路径。可选择预测点数和时间步长。各平台独立预测，综合平台预测由其他平台加权合成。预测结果以球体和虚线显示，支持动画播放。

{{ icon_chart() }} 数据分析

多维运动学指标曲线：高度、速度、加速度、曲率。原始数据与预测数据拼接为连续曲线。底部最佳捕捉时机卡片需先执行预测，基于加权评分给出前三名捕捉时间点与坐标。

{{ icon_ai() }} AI 策略

大语言模型分析多平台轨迹数据，生成无人机反制捕捉建议。勾选参与分析的平台，结果可保存至 reports/ 目录。

{{ icon_database() }} 数据管理

上传 .dat 格式文件（每行 x y z t）为自选平台。支持备份快照、恢复、列表查看。更新全部数据可重置出厂轨迹并清空自选和预测。

键盘与鼠标

  • WASD — 摄像头前后左右平移
  • QE — 摄像头升降
  • Space — 播放 / 暂停动画
  • 左键拖拽旋转 · 右键拖拽平移 · 滚轮缩放

数据格式

轨迹文件为 .dat 纯文本，每行空格分隔：

x y z t
0.0 2.0 9.0 0.0
1.5 2.3 8.5 0.2
3.2 2.8 7.1 0.4

综合轨迹自动合成；预测文件在启动时清除，需重新生成。
