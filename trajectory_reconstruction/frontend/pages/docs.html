鹰眼长空 — 基于多平台协同的低空无人机智能监测系统

快速入门

鹰眼长空是一个多平台协同的无人机轨迹监测与分析系统。系统集成了可见光、红外、雷达三种检测平台，提供轨迹重建、预测、分析与 AI 策略生成功能。

启动方式

  • 桌面应用模式：python main.py
  • 仅轨迹重建：python main.py recon
  • 纯 HTTP 模式（无窗口）：python main.py --headless
  • 重建模块将运行在 http://127.0.0.1:5000
  • 识别模块将运行在 http://127.0.0.1:5001

键盘快捷键

  • Space — 播放 / 暂停轨迹动画
  • 鼠标左键拖拽 — 旋转 3D 视图
  • 鼠标滚轮 — 缩放视图
  • 鼠标右键拖拽 — 平移视图

功能模块

{{ icon_target() }} 总览（Dashboard）

全屏 3D 视图展示所有平台的轨迹数据。左侧面板可切换各平台可见性，右侧面板显示实时平台状态（速度、高度、航向角）。底部控制栏支持轨迹动画播放，可调节播放速度，拖动进度条跳转到任意时刻。鼠标悬停在轨迹数据点上可查看精确三维坐标。

{{ icon_predict() }} 轨迹预测

基于历史轨迹数据，使用多项式拟合算法预测未来飞行路径。可选择预测目标平台（全部或单一平台），调节预测点数和时间步长。预测结果以虚线+半透明球体显示在 3D 视图中，支持动画播放历史和预测全程。

{{ icon_chart() }} 数据分析

多维度运动学指标分析，包括：

  • 高度变化曲线 — 展示飞行高度随时间变化
  • 速度变化曲线 — 瞬时速率变化趋势
  • 加速度变化曲线 — 加速/减速时段识别
  • 曲率变化曲线 — 转弯剧烈程度评估

{{ icon_ai() }} AI 策略

利用大语言模型分析多平台轨迹数据，自动生成无人机反制捕捉策略建议。可选择参与分析的检测平台，生成结果可保存为报告文件（存储在 reports/ 目录）。生成的文本在页面切换时会自动保留。

{{ icon_database() }} 数据管理

提供完整的轨迹数据生命周期管理：

  • 上传 — 支持 .dat 格式（每行: x y z t），可指定目标平台
  • 备份 — 一键创建数据快照，支持多版本备份文件
  • 恢复 — 从备份列表中选择恢复，或一键恢复最新备份
  • 清理 — 清空全部数据前自动备份到 backup/ 目录

常见问题

如何添加自定义轨迹数据？

在「数据管理」页面使用上传功能，选择 .dat 格式文件。每行应为：x y z t（空格分隔，t 为时间戳）。上传后可选择分配到的检测平台。

预测不准确怎么办？

预测质量依赖于历史数据点的数量和质量。可尝试：增大预测点数滑块、减小时间步长、确保选择的数据有足够的历史点。算法使用三阶多项式拟合，适合平滑轨迹。

AI 策略不生成？

请确认：已正确配置 config.json 中的 AI 提供商信息、网络连接正常、至少选择一个平台的分析数据。如果持续失败，请检查终端日志中的 API 错误信息。

如何切换明暗主题？

前往「设置」页面，点击主题切换开关即可在深色/浅色模式间切换。选择会自动保存，下次打开自动应用。
