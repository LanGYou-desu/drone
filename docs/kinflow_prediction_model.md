# KinFlow 无人机轨迹预测模型

> 实现依据：*KinFlow: A Learned Kinematic Prior with Parallel Non-Autoregressive Refinement
> for Irregularly-Sampled UAV Trajectory Prediction*（Applied Intelligence，稿号 APIN-D-26-14134）
>
> 代码位置：`trajectory_reconstruction/core/prediction/kinflow/`、`train/kinflow_predictor/`

---

## 1. 一句话概括

KinFlow 用**一个闭式的运动学先验**替代自回归解码：连续时间 Transformer 把不规则历史编码为
上下文向量，一个小 MLP 回归初速度与加速度，在真实未来时间戳上**闭式**外推出常数加速度走廊；
再由一个用**条件流匹配（CFM）**训练的轻量速度场，从走廊出发做少量**并行** Euler 步完成细化；
最后用一个**非参数可微投影器**把速度、垂直速率、高度投影到四旋翼可行域内。
整个 K 步未来在一次前向中产生，不存在逐步迭代，也不存在误差沿时间累积。

## 2. 问题定义

给定 N 个不规则采样的历史位置 `{(t_i, p_i)}_{i=1}^{N}`，`p_i = (x_i, y_i, z_i)`，
以及未来时间戳 `τ_1 … τ_K`，预测 `p̂_{N+k}`。预测必须满足四旋翼约束：

| 约束 | 符号 | 本项目默认值 |
|------|------|--------------|
| 最大水平速度 | `v_h ≤ v_h,max` | 20 m/s（`kinflow_model.v_h_max`） |
| 最大上升速度 | `v_y ≤ v_up,max` | 5 m/s |
| 最大下降速度 | `v_y ≥ -v_down,max` | 3 m/s |
| 最大倾角（水平加速度） | `a_h ≤ g·tan(φ_max)` | 35° → 6.87 m/s² |
| 高度范围 | `y_min ≤ y ≤ y_max` | 1 ~ 120 m |

> 默认值与 `config.json → drone_dynamics` 对齐（本项目的轨迹生成器、检测世界坐标与
> 投影器共用同一套包线）。论文在公开数据集上使用更严的 10 / 4 / 2 m/s、30°、2~100 m；
> 需要严格复现论文设置时，把 `kinflow_model` 与 `training` 中的边界改成论文值即可。

> **坐标约定**：本项目位置为 `[x, y, z]`，其中 **y 为垂直轴**（高度），x/z 构成水平面，
> 与论文 `altitude y_min ≤ y ≤ y_max` 的写法一致。该约定在系统各处已实测核对（见 §7.6）：
> 训练数据集（`.npz`）、运行时轨迹（`data/fact/*.dat`）、检测世界坐标
> （`detection_service._to_world`：X=右 / Y=上 / Z=前）、分析页高度（`p[1]`）、
> Three.js 可视化（坐标原样映射，默认 +Y 向上）全部一致。

## 3. 总体架构

```text
历史 (t_i, p_i, Δt_i, v_i^est)
        │
        ▼
┌─────────────────────────────────────────┐
│ ① ContextEncoder  (encoder.py)          │  4 层 Pre-LN Transformer, 4 头, d_f=64
│   f_i = Linear7→64([Δt_i; p_i; v_i^est])│  + 连续时间正弦编码 + CLS token
│   c = MLP_ctx(Transformer(CLS, f+e)_CLS)│  → c ∈ R^128
└─────────────────────────────────────────┘
        │ c
        ▼
┌─────────────────────────────────────────┐
│ ② KinematicCorridor  (corridor.py)      │  MLP(c, p_N) → (v_0, a)
│   X0[k] = p_N + v_0·Δτ_k + ½·a·Δτ_k²    │  闭式求值于真实 τ_k（规则/不规则均可）
└─────────────────────────────────────────┘
        │ X0 ∈ R^{K×3}
        ▼
┌─────────────────────────────────────────┐
│ ③ CorridorFlow  (flow.py)               │  条件流匹配速度场 v_θ
│   X ← X + (1/n)·v_θ(X, i/n, c, τ)       │  n=4 并行 Euler 步，全部 K 步同时推进
└─────────────────────────────────────────┘
        │ X（归一化坐标）
        ▼
┌─────────────────────────────────────────┐
│ ④ PhysicsProjector  (projector.py)      │  非参数、可微、3 次迭代
│   速度→垂直速率→高度扫描→累加重建        │  输出物理坐标、满足硬约束
└─────────────────────────────────────────┘
        │
        ▼
    X̂ ∈ R^{K×3}（物理坐标）
```

## 4. 各模块细节

### 4.1 连续时间上下文编码器（`encoder.py`）

每个历史点构造 7 维特征：

```text
f_i = Linear_{7→d_f}( [ Δt_i ; p_i ; v_i^est ] ),   Δt_1 = 0
```

`v_i^est` 由中心差分（内部点）与单侧差分（端点）估计（`math_utils.estimate_velocity`），
让编码器直接获得"在哪、何时、多快、朝哪"三类信息，无需自行从坐标反推。

时间编码为连续时间正弦/余弦对：

```text
e_i = [ sin(ω_1 t_i), cos(ω_1 t_i), …, sin(ω_{d_f/2} t_i), cos(ω_{d_f/2} t_i) ]
```

- 把任意实数时间映射为有界周期特征，无需分箱、填充、插值，天然支持不规则采样；
- 频率在对数尺度 `[0.1, 10] rad/s` 上取值，覆盖从缓慢爬升到快速机动的运动尺度。

> **数值实现说明**：正弦编码在时间平移下只相差相位，编码器依赖的是相对时间；
> 实现中传入的是相对窗口起点的时间 `t_i - t_1`，与论文的绝对时间编码等价，
> 但避免了 float32 在大时间戳下的精度损失。

Transformer 为 4 层 Pre-LN、4 头、FFN 256，前置 CLS token 聚合整段历史，
CLS 输出经 `MLP_ctx` 得到上下文 `c ∈ R^{128}`。

### 4.2 运动学走廊先验（`corridor.py`）

```text
(v_0, a) = MLP_corr( c, p_N )                     # 隐藏层 128，输出 6 维
X_0[k]   = p_N + v_0·Δτ_k + ½·a·Δτ_k²,  Δτ_k = τ_k - t_N
```

要点：

- **从整段历史回归** `(v_0, a)`，而不是局部有限差分 —— 这是它显著优于经典
  CA-Kalman 滤波器的原因（论文用全历史最小二乘 CA 消融证明了"全历史"因素本身不够）；
- 闭式求值意味着可以在**任意**未来时间戳查询，不需要网格，也不会逐点抖动；
- 先验本身不做边界裁剪，边界交给物理投影器，走廊保持纯解析；
- 辅助损失 `MSE(X_0, X_gt)`（权重 `λ_c = 1.0`）独立回归先验，避免生成目标主导先验拟合；
- 输出层用 `std=0.02` 的小初始化，训练初期先验接近静止点，再逐步学到真实速度/加速度。

### 4.3 走廊初始化的整流流（`flow.py`）

**训练（条件流匹配）**。以走廊 `X_0` 为源、真实轨迹 `X_1` 为汇：

```text
X_t = (1 - t)·X_0 + t·X_1,     t ~ U[0, 1]
L_flow = E_t[ ‖ v_θ(X_t, t, c, τ) − (X_1 − X_0) ‖² ]
```

这是纯回归问题："给定走廊、上下文和未来时刻，还差多少、往哪个方向挪"。
与扩散不同，它不需要加噪/去噪的调度，训练更稳、收敛更快。

**推理（并行 Euler 采样）**：

```text
X ← X_0 (+ σ·ε, 概率采样时)
X ← X + (1/n)·v_θ(X, i/n, c, τ),   i = 0 … n−1      # 默认 n = 4
```

由于源（走廊）已经接近目标，传输距离很短：论文测得的传输距离从噪声初始化的 1.685 m
降到走廊初始化的 0.114 m，因此 4 步即接近收敛；`σ = 0` 得到确定性均值预测，
`σ = 0.1` 得到围绕均值的单峰预测分布。

**网络结构**（双分支 + 时间注意力）：

```text
全局分支:  z_gen = MLP( c, X_0^flat ) ∈ R^{d_z}
逐点分支:  v_k   = MLP_step( [ x_k ; Emb(τ_k) ; Emb(t) ; z_gen ] ) ∈ R³
时间相干:  v     = v + mean-softmax-attention(v 的隐状态) 单头注意力
```

- 逐点 MLP 在 K 个时间步间共享参数；
- 输出层**零初始化**：训练早期采样结果停在走廊先验上，不会破坏先验质量；
- `z_gen` 的全局条件与请求的预测点数 **K 无关**：推理时若 K ≠ `k_max`，全局分支始终读取
  同一段 `k_max` 步参考走廊 `x0_ref`（在 `sample_dt` 栅格上由同一组 `(v_0, a)` 闭式求值）。
  否则界面上的"预测点数"滑块会改变首步预测（实测 K=10 与 K=6 的首步相差 0.29 m）。

### 4.4 可微物理投影器（`projector.py`）

非参数（0 个可学习参数），单次前向完成，默认迭代 R = 3 次。每次迭代：

1. 把轨迹反归一化到物理坐标，以 `p_N` 为锚点逐步差分得到每步速度；
2. **水平速度**整体缩放到 `v_h,max`（保持朝向不变）；
3. **垂直速度**裁剪到 `[-v_down,max, v_up,max]`（上升/下降能力不对称）；
4. **前向扫描**：逐步限制垂直速度，使到达高度始终位于 `[y_min, y_max]`，
   避免"硬裁剪高度"造成的速度尖峰；
5. 用受限速度按 `Δτ_k` 累加重建位置。

由于速度已被约束、位置又完全由速度重建，第一次迭代后结果不再变化，
剩余迭代仅作为分布外输入的保险。输出轨迹的**速度、垂直速率、高度违反率恒为 0**；
加速度是耦合相邻步的约束，没有单点闭式投影，因此只由软损失近似（见 §5），
其残余违反率会在训练/测试指标中如实报告（`viol_accel`）。

> 高度保证成立的前提是锚点 `p_N` 本身位于 `[y_min, y_max]` 内。

### 4.5 非自回归预测

```text
X̂ = Projector ∘ Flow ∘ Corridor ∘ Encoder(history)
```

没有组件沿时间步迭代：K 步未来在一次前向中并行产生，延迟与 K 基本无关，
误差也不会像自回归模型那样逐步累积。

## 5. 训练策略

### 5.1 阶段一 —— 联合训练

```text
L = L_flow + λ_c·MSE(X_0, X_gt) + λ_p·L_phy,     λ_c = 1.0, λ_p = 0.01
```

- 走廊项让先验贴近数据，流项学习残差，物理项把生成结果拉向可行域；
- `L_phy` 在**中点插值** `X_0.5 = (X_0 + X_gt)/2` 上、于物理坐标中计算，
  作为可微代理避免只在采样末端施加约束造成的稀疏梯度；
- `L_phy` 含水平速度、垂直速率、高度、水平加速度四类平方 hinge 违反量；
- 物理权重 `λ_p = 0.01` 远小于其它两项：它只做"柔性引导"，硬保证交给部署时的投影器。

### 5.2 阶段二 —— 微调

推理时的概率采样会向走廊注入噪声；如果训练中流从未见过被扰动的走廊，
这一输入分布偏移会在部署时表现为精度下降。因此阶段二：

- 学习率更低（`lr_stage2 = 1e-4`，默认 `1e-3`）；
- 向走廊先验注入噪声 `σ = 0.1`（归一化坐标），让生成器见到与推理时相同的输入分布；
- 可选地把可微投影器放入计算图（`projector_in_graph = true`，权重 `λ_proj = 0.1`，
  2 步 Euler 采样 + 投影 → 与真值比较），进一步缩小训练/部署差距。

### 5.3 优化设置

| 项目 | 取值 |
|------|------|
| 优化器 | AdamW，weight decay `1e-4` |
| 梯度裁剪 | max-norm `1.0` |
| 学习率调度 | warmup 5 epoch + 余弦退火（阶段一从 `1e-3`，阶段二从 `1e-4`） |
| 批次 | 默认 32（可 `--batch` 覆盖） |
| NaN 保护 | loss 非有限时跳过该批次梯度更新 |

## 7. 数据与预处理

### 7.1 数据格式

```text
train/kinflow_predictor/dataset/
├── train/   traj_*.npz      # positions (N,3) float32 + timestamps (N,)
├── valid/   traj_*.npz
├── test/    traj_*.npz
└── data/                    # 回退目录（无 train/ 时自动按 85/15 切分）
```

也兼容 `.dat`（每行 `x y z t`，空格分隔）。

### 7.2 窗口与切分

- 上下文长度 `C = 40`（3.9 s @ 0.1 s），目标长度 `K = 20`（2 s）；
- 窗口间 stride = `min(C/2, K/2) = 10`，相邻窗口重叠但完全冗余；
- 更长的历史/目标窗口让模型能感知转弯趋势，也把"模型可靠视界"从 1 s 提升到 2 s；
- 数据集**按轨迹级**切分（3819 / 763 / 511），同一轨迹的窗口不会跨集合泄漏。

### 7.3 训练期增强

- 绕垂直轴（Y 轴）随机旋转，仅当爬升角 < 30° 时施加（对爬升为主的轨迹无意义）；
- 随机缩放 0.9 ~ 1.1 倍；
- 相对数据标准差 0.5% 的高斯噪声。

### 7.4 不规则采样增强

公开数据集是固定 0.1 s 采样，而 KinFlow 的核心卖点是**不规则采样鲁棒性**。若训练中
编码器只见过单一 Δt，`Δt` 特征与连续时间编码就形同虚设。因此训练窗口会额外施加
时间抖动（`training.time_jitter = 0.35`）：

- 历史时间戳首尾固定，中间点抖动 ±35% × 名义 dt；
- 强制严格递增，并在原轨迹上按扰动后的时刻线性重采样位置；
- 重新计算 `Δt` 与中心差分速度。

验证/测试集**不做**该增强，保证评价与真实采样一致。

### 7.5 归一化

逐轨迹逐轴 Z-score。统计量**只由历史窗口计算**（推理时同样只有历史可见），
且每轴标准差有物理下限 `POSITION_STD_FLOOR = 0.25 m`：
平飞轨迹的垂直/侧向变化可能只有几厘米，若无下限，归一化坐标会被放大几十倍，
流匹配回归的数值尺度会严重失衡。该下限在训练与推理中使用同一常量，保证一致。

### 7.6 坐标与单位一致性核对

**结论：训练集与运行时轨迹同为 Y 轴向上，单位同为米/秒，坐标系一致。**

| 维度 | 训练数据集 `dataset/train/*.npz` | 运行时轨迹 `data/fact/*.dat` | 是否一致 |
|------|----------------------------------|------------------------------|----------|
| 垂直轴 | y，取值 4.9 ~ 23.0 m | y，取值 0.0 ~ 3.9 m | ✅ 均为高度轴 |
| 水平面 | x ∈ ±44 m，z ∈ ±44 m | x ∈ [-0.8, 19.6] m，z ∈ [-1.3, 9.0] m | ✅ 均为水平面 |
| 运动占比 | x 41% / y 16% / z 43% | x 50% / y 20% / z 30% | ✅ 水平机动为主 |
| 单位 | 米、秒 | 米、秒 | ✅ |
| 采样间隔 | 固定 0.1 s | 0.1 ~ 0.2 s | ⚠️ 已用时间抖动增强覆盖（§7.4） |
| 时间基准 | 每条轨迹从 0 起 | 每条轨迹从 0 起 | ✅ |

代码侧交叉验证：

- `trajectory_recognition/services/detection_service.py::_to_world` 明确输出
  `世界坐标系 (X=右 Y=↑ Z=前)`；
- `trajectory_reconstruction/views/analysis.py` 的高度取 `p[1]`；
- 前端 `three-utils.js / dashboard.js` 把 `(x,y,z)` 原样映射到 Three.js（默认 +Y 向上）；
- `config.json → drone_dynamics` 的 `min_alt / max_alt` 作用于 y 轴。

核对过程中发现并修复了两处**真实的不一致**：

1. **物理包线默认值**：初版沿用论文的 10 / 4 / 2 m/s、30°、2~100 m，但本项目动力学配置为
   20 / 5 / 3 m/s、35°、1~120 m，且运行时示例轨迹常在 y ≈ 0~4 m 飞行（低于论文的
   `y_min = 2`）。已把默认值对齐 `drone_dynamics`；同时投影器在锚点越出高度包线时，
   把允许区间扩展为包含锚点，只阻止继续向界外运动，不再"凭空"把轨迹抬进包线。
2. **采样间隔**：数据集固定 0.1 s，运行时为 0.2 s。已在训练中加入时间抖动增强（§7.4），
   让编码器的 `Δt` 特征与连续时间编码真正见过不规则间隔。

## 8. 评估指标

| 指标 | 说明 |
|------|------|
| 归一化 MSE | 走廊先验在归一化坐标下的拟合误差（`mse_norm_corridor`） |
| ADE | 物理坐标下沿预测时域的平均欧氏误差（米） |
| FDE | 末端点欧氏误差（米） |
| minADE_8 | `σ=0.1` 采样 8 条轨迹的 best-of-K 平均 ADE |
| `viol_speed` / `viol_vertical` / `viol_altitude` | 物理坐标下的违反率（投影器保证为 0） |
| `viol_accel` | 水平加速度软约束的残余违反率 |
| 延迟 | 单窗口推理毫秒数（Euler 步数固定） |

训练曲线与测试图表输出到 `train/kinflow_predictor/train_result/run_<时间戳>/`。

| `enabled` | `true` | 是否启用 KinFlow（关闭后走线性外推） |
| `v_h_max` | `20.0` | 最大水平速度（m/s） |
| `v_up_max` | `5.0` | 最大上升速度（m/s） |
| `v_down_max` | `3.0` | 最大下降速度（m/s） |
| `max_tilt` | `35.0` | 最大倾角（度），决定水平加速度上限 |
| `y_min` / `y_max` | `1.0` / `120.0` | 高度范围（m） |
| `n_euler_steps` | `4` | 并行 Euler 采样步数 |

下一次预测按新参数重新加载。

### 9.3 推理实现细节（与训练的严格对齐）

推理入口 `KinFlow.predict()` 做了三步规整，保证任意输入轨迹都落在训练分布内：

1. **历史重采样到训练栅格**：训练窗口是 C=40 点、名义间隔 `sample_dt`=0.1 s（3.9 s）。
   运行时轨迹长度/间隔各异，若直接把整段历史喂给模型，逐轴 Z-score 的标准差会随窗口
   跨度变化，归一化速度尺度随之漂移。因此统一取末尾 3.9 s、等间隔重采样为 40 点。
   （注意：`load_kinflow_model` 必须把检查点里的 `ctx_len/sample_dt` 传给模型，
   否则会用 20 点短窗口推理，实测 ADE 会从 0.2 m 恶化到 1 m 以上。）
2. **短/中视界（≤2 s）**：直接在请求的 `num_points × time_step` 时间戳上并行生成，
   支持 3~60 点、0.05~5 s 步长，流匹配以 τ 为条件。
3. **长视界（>2 s）**：前 2 s 由模型生成；其后以模型段末端的航向、转率、水平速度、
   垂直速度做**常转率积分**（转率按 6 s 指数衰减，不做持续加速），
   逐点置信度 `exp(-(t-2)/8)` 衰减（最低 0.15）。
4. **物理投影**：全段统一经投影器约束速度/垂直速率/高度。

> 长视界片段只保证运动学一致与趋势合理（不会退化成直线，也不会越推越快），
> 不保证精度；界面会显示末端置信度。短视界示例：1 s 位移 4 m、2 s 8 m；
> 长视界示例：10 s 位移 35 m、末端置信度 0.37。

### 9.4 权重查找与回退

推理权重按以下顺序查找（取第一个存在的）：

1. `train/kinflow_predictor/train_result/best/kinflow_best_s2.pt` → `..._s1.pt`
2. `models/kinflow/kinflow_best_s2.pt` → `..._s1.pt`
3. `models/kinflow/kinflow_s*_v{loss}.pt`（按 loss 升序取最优）
4. `models/kinflow/kinflow.pt`

任一环节失败（权重缺失、被禁用、CUDA 不可用、加载或推理异常、历史点不足 5 个）
都会自动回退到**线性外推**，不会中断预测流程。

## 10. 与旧模型（Phy-ODE-Diffusion）的差异

| 维度 | Phy-ODE-Diffusion（旧，已归档） | KinFlow（当前） |
|------|--------------------------------|-----------------|
| 解码 | 逐点自回归（ODE 演化 + GRU 更新） | 一次并行生成全部 K 步 |
| 生成模型 | 物理引导扩散，DDIM 50~80 步 | 走廊初始化流匹配，4 步 Euler |
| 先验 | 神经 ODE 积分 | 闭式常数加速度走廊 |
| 物理约束 | 采样过程中的梯度引导 | 非参数可微投影器（硬约束） |
| 参数量 | ~482K | 368K |
| 误差累积 | 沿时域累积 | 无累积 |
| 权重命名 | `phy_ode_diffusion_*.pt` | `kinflow_*.pt` |

旧代码、权重、训练产出与文档已归档在 `backup/legacy_phy_ode/`，当前系统不再引用。

## 11. 已知限制

- **单峰假设**：σ 注入的流给出单峰、以均值为中心的预测分布，
  不适合多模态机动（如急转弯前后两种意图）；论文亦明确不宣称良好校准，项目未报告 CRPS/覆盖率。
- **合成数据**：主训练数据为参数化航点 + 样条 + 动力学约束生成的合成轨迹，
  真实场景的传感器失效、遮挡突变需要额外微调。
- **高度保证前提**：投影器的高度约束以锚点在 `[y_min, y_max]` 内为前提（锚点越界时把允许区间扩展为包含锚点，只阻止继续越界）；
  锚点越界时只保证区间非空，不保证绝对符合。
- **加速度仅软约束**：`viol_accel` 通常非零，属设计取舍（见 §4.4）。
- **长视界精度有限**：>2 s 由运动模型外推，只保证趋势与运动学一致，置信度随时间下降。
