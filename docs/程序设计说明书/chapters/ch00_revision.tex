\section*{版本说明（V2.0）}
\addcontentsline{toc}{section}{版本说明（V2.0）}

本说明书 V1.0 描述的是以 Phy-ODE-Diffusion 为预测内核的初版系统。2026 年 11 月完成的
V2.0 重建了预测与协同链路，并对页面结构做了整合。为避免文档与软件不一致，本节集中说明
修订内容与各章的有效性；正文中与本节点名冲突的部分，以本节与对应专项文档为准。

\subsection*{主要变更}

\begin{enumerate}
  \item \textbf{预测内核替换为 KinFlow}：连续时间编码器（40 点 / 3.9 s 历史）
        $\rightarrow$ 运动学走廊先验 $\rightarrow$ 走廊初始化流匹配（2 s 视界，4 步 Euler）
        $\rightarrow$ 可微物理投影器，参数量约 372K；测试集 ADE 0.495 m / FDE 1.324 m。
        旧 Phy-ODE-Diffusion 代码、权重与训练产物已归档至 \file{backup/legacy_phy_ode/}。
  \item \textbf{长视界分段预测}：视界 $\leq 2$ s 由模型直接生成；$>2$ s 的前 2 s 为模型预测，
        其后由常转率运动模型外推（转率 6 s 指数衰减），逐点置信度随视界衰减并在界面显示。
        支持 3--60 点、0.05--5 s 步长。
  \item \textbf{多传感器协同链路}：时间步同步（时钟偏置估计）$\rightarrow$ 一致子集关联
        $\rightarrow$ 逆方差融合 $\rightarrow$ 三维重建（剔除/补洞/平滑/置信度）$\rightarrow$
        六因子风险评估。"综合轨迹"即重建结果，在总览页以青色管状体显示。
  \item \textbf{页面整合}：撤销独立的"重建"与"评估"页面，重建并入总览，分析与评估合并为
        "分析评估"页；导航为 总览 / 预测 / 分析评估 / AI 策略 / 数据（另有帮助、设置）。
  \item \textbf{参数持久化}：重建参数与防护区/评估视界写回 \file{config.json}，预测点数/步长
        与数据源选择记入浏览器 localStorage，刷新与重启后保持。
  \item \textbf{演示数据}：\file{tools/make_runtime_demo.py} 生成同一目标的三路异构观测
        （5/4/10 Hz、不同噪声、时钟偏置、遮挡、丢帧），替代原先"三路不同目标"的演示数据。
\end{enumerate}
