# 鹰眼长空 — 使用手册

基于多平台协同的低空无人机智能监测系统。

## 快速开始

```bash
pip install -r requirements.txt
python main.py               # 桌面窗口 → http://127.0.0.1:5000
python main.py --headless    # 纯 HTTP 模式
```

编辑 `config.json` 填入 API Key 后可使用 AI 策略。

## 界面总览

系统有 5 个功能页面，顶部导航栏切换。支持深色/浅色双主题（设置页面切换）。

### 总览
全屏 3D 轨迹视图。左侧面板切换平台显隐，右侧面板实时状态（点击标题折叠）。底部播放控制条。

**操作：** 鼠标左键旋转 · 滚轮缩放 · 右键平移 · **WASD** 飞行 · **QE** 升降 · **Space** 播放 · 悬停轨迹点查看坐标和时间

### 预测
选择平台 → 调整点数/步长 → 点击"开始预测"。综合轨迹预测由其他平台加权合成。

### 分析
高度/速度/加速度/曲率四张图表，原始+预测拼接显示。底部卡片给出最佳捕捉时机（需先预测）。

### AI 策略
勾选平台 → 生成捕捉策略 → 可保存为报告。

### 数据
上传 `.dat` 文件（每行 `x y z t`）创建自选平台；备份/恢复/更新数据。

## 配置要点

`config.json` 关键字段：

| 字段 | 说明 |
|------|------|
| `ai.api_key` | AI 接口密钥 |
| `detection_methods.<id>.weight` | 综合轨迹合成权重（默认 1.0） |
| `capture_weights` | 捕捉时机评分权重 |
| `camera_speed` | WASD 移动速度（默认 0.12） |
| `theme` | 默认主题（dark / light） |

## 数据格式

`.dat` 文件，每行空格分隔 `x y z t`（坐标 + 秒）。

## 常见问题

**预测后分析页没数据？** 需先执行预测，综合轨迹预测至少需要两个平台有数据。

**切换主题？** 设置页面点击切换，自动保存。

**自选平台不显示？** 上传 .dat 数据后自动出现，重启清空。

**动画球体消失？** 按 Space 是暂停，刷新页面清除。
