# 变更记录

## V2.0 — 2026-11

以 KinFlow 为核心重建预测与协同链路，并整合页面结构。

### 预测
- 预测内核由 Phy-ODE-Diffusion 替换为 **KinFlow**：连续时间编码器（40 点 / 3.9 s）
  → 运动学走廊先验 → 走廊初始化流匹配（2 s 视界，4 步 Euler）→ 可微物理投影器，约 372K 参数。
- 修复推理加载器漏传 `ctx_len/sample_dt` 导致的窗口错配（ADE 0.2 m → 1 m 级退化）。
- 测试集（2 s 视界）：**ADE 0.495 m / FDE 1.324 m**，切点评估优于线性外推约 4 倍。
- 长视界分段预测：>2 s 由常转率运动模型外推（转率 6 s 指数衰减），返回逐点置信度；
  支持 3~60 点、0.05~5 s 步长。
- 预测段改为与轨迹一致的视觉语言：综合轨迹为细青色管，单平台为同色实线 + 小点。

### 多传感器协同
- 新增 `core/timesync.py`（时钟偏置估计 + 主时间栅格）、`core/fusion.py`（一致子集选择 +
  关联 + 逆方差融合 + 健康度）、`core/reconstruction.py`（剔除/补洞/平滑/置信度）、
  `core/risk.py`（六因子评估）、`core/sensor_sim.py`（同目标仿真）。
- “综合轨迹”改为重建结果，总览页以青色管状体显示，左侧面板展示质量指标并支持调参重建。
- 新增 `/api/sensors/status|reconstruct|assess` 与 `/api/synthesize` 参数化重建。

### 界面
- 导航整合为 总览 / 预测 / 分析评估 / AI 策略 / 数据（+ 帮助、设置），撤销独立“重建”“评估”页。
- 分析评估合并页：风险总分 + 评估参数 → 时间线 → 因子/建议 → 证据/预测事件 →
  最佳捕捉时机（三列卡片）→ 运动学图表。
- 3D 场景增加圆柱形防护区；播放时隐藏平台不再出现目标点。
- 去 emoji/符号，统一自绘 SVG 图标。

### 数据与参数
- 新增 `tools/make_runtime_demo.py`：一条真值轨迹 + 三路同目标异构观测（5/4/10 Hz、
  不同噪声、时钟偏置、遮挡、丢帧）。
- 重建参数与防护区/评估视界写回 `config.json`；预测点数/步长与数据源记入 localStorage。

### 训练
- 默认窗口 `ctx_len=40`、`tgt_len=20`、`k_max=20`；`λ_c=0.5`、`λ_sample=0.3`、batch 64。
- 集中 `best/` 目录只接受更优验证损失，避免冒烟/短训练覆盖部署权重。

### 文档与验收
- 更新 README、使用手册、配置说明、开发文档、KinFlow 模型说明、协同说明、模块 README。
- 《程序设计说明书》升级 V2.0，新增“版本说明”与章节有效性对照。
- `docs/acceptance/run_collab_acceptance.py` 覆盖页面、重建、预测联动、评估、隐藏播放与参数持久化。
